# แผนเข้ามหาวิทยาลัย TCAS70
เว็บแอปวางแผนสอบเข้ามหาวิทยาลัย: กรอกคะแนน, ตั้งเป้าหมายคณะ/สาขา, นับถอยหลังกำหนดการ

## โครงสร้าง
- `index.html` หน้าเว็บหลัก
- `css/style.css` สไตล์
- `js/data.js` ข้อมูลวิชา กำหนดการ เช็กลิสต์
- `js/storage.js` บันทึกข้อมูลใน localStorage
- `js/calc.js` สูตรคำนวณคะแนนถ่วงน้ำหนักและสถานะ
- `js/home.js` หน้าภาพรวม
- `js/explore.js` เลือกมหาวิทยาลัย/คณะ
- `js/app.js` ส่วนแสดงผลและควบคุมแอป
- `assets/` ไอคอน

## วิธีใช้
เปิด `index.html` ในเบราว์เซอร์ หรือเปิดผ่าน GitHub Pages
